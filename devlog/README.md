# 開發日誌 (Devlog)

記錄每天 / 每次開發階段的實際進度、遇到的問題與決策原因。
與其他文件的分工：

- `design_docs/` — 動工前的規劃與設計方案
- `docs/` — 完成後的正式說明文件（CI/CD、架構等）
- `devlog/` — 過程紀錄：今天做了什麼、為什麼這樣做、卡在哪裡

## 檔名規則

```
YYYY-MM-DD-短標題.md
```

例：`2026-08-06-blade-carousel-polish.md`。同一天有多篇時加序號：`2026-08-06-01-...`。

## 每篇建議格式

```markdown
# YYYY-MM-DD 標題

## 今天做了什麼
- 

## 遇到的問題 / 解法
- 

## 決策紀錄
- 決定：
  - 原因：
  - 放棄的選項：

## 下一步
- 
```

可直接複製 [`_template.md`](_template.md) 開新的一篇。
